# 50/50 split inventory (version at tag `pre-apple-standard`)

Every homepage act was a 50/50 split (`components/split/SplitAct.tsx`), with a fixed divider between the halves.

| Section | Split | Decision |
|---|---|---|
| Title (h1 across two halves, document left, structure list right) | yes | **Replaced** by a centred headline over a full-width pinned document stage with the structure scan |
| Listen (two players, one per half) | yes | **Replaced** by one centred document, a single player with an As posted / After repair switch, and a caption line |
| Scale (file wall left, groups right) | yes | **Replaced** by a full-width file field that sorts into five full-width lanes |
| Journey (sticky sheet left, stages right) | yes | **Replaced** by one large workspace frame with a stage switcher; panels live inside the product UI |
| Value (sliders left, results right) | yes | **Replaced** by full-width results first, then a three-column control grid |
| Trust (software checks left, people checks right) | yes | **Replaced** by one full-width six-step method line plus a centred report |
| Close (two-column offer plus document) | 7/5 grid | **Replaced** by a centred conclusion over the resolved document; the offer becomes its own centred chapter |
| Divider (`split/Divider.tsx`) | the split itself | **Removed** |
| Contact page (copy left, form right) | 5/7 | **Kept.** A form page is a familiar task layout; it is not homepage storytelling |
